# SI Units

The International System of Units (SI) is the internationally recognized system of measurement used in science, engineering, industry, and many areas of everyday life.

SI provides a consistent framework for defining and using measurement units.

## SI Base Units

The SI system has seven base units.

| Physical Quantity         | SI Base Unit | Symbol |
| ------------------------- | ------------ | ------ |
| Length                    | metre        | m      |
| Mass                      | kilogram     | kg     |
| Time                      | second       | s      |
| Electric current          | ampere       | A      |
| Thermodynamic temperature | kelvin       | K      |
| Amount of substance       | mole         | mol    |
| Luminous intensity        | candela      | cd     |

## SI Derived Units

Many physical quantities are expressed using derived SI units.

| Quantity               | SI Unit | Symbol |
| ---------------------- | ------- | ------ |
| Frequency              | hertz   | Hz     |
| Force                  | newton  | N      |
| Pressure               | pascal  | Pa     |
| Energy                 | joule   | J      |
| Power                  | watt    | W      |
| Electric charge        | coulomb | C      |
| Voltage                | volt    | V      |
| Capacitance            | farad   | F      |
| Electrical resistance  | ohm     | Ω      |
| Electrical conductance | siemens | S      |
| Magnetic flux          | weber   | Wb     |
| Magnetic flux density  | tesla   | T      |
| Inductance             | henry   | H      |
| Luminous flux          | lumen   | lm     |
| Illuminance            | lux     | lx     |

## Examples of Derived Units

### Force

The newton is the SI unit of force.

**1 N = 1 kg·m/s²**

### Pressure

The pascal is the SI unit of pressure.

**1 Pa = 1 N/m²**

### Energy

The joule is the SI unit of energy.

**1 J = 1 N·m**

### Power

The watt is the SI unit of power.

**1 W = 1 J/s**

## SI Prefixes

SI prefixes are used to express decimal multiples and submultiples of units.

Examples include:

* kilo (k) = 10³
* mega (M) = 10⁶
* giga (G) = 10⁹
* milli (m) = 10⁻³
* micro (µ) = 10⁻⁶
* nano (n) = 10⁻⁹

For a complete list of SI prefixes, see:

[Metric Prefixes](metric-prefixes.md)

## SI Units and Unit Conversion

Using consistent SI units can simplify calculations and reduce unit-related errors.

For example:

**1 km = 1,000 m**

**1 kg = 1,000 g**

**1 kW = 1,000 W**

When working with non-SI units, appropriate conversion factors should be applied before combining measurements in a calculation.
